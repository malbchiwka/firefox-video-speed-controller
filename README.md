# Ускоритель видео для Firefox (Speed Controller)

Легковесное расширение для Mozilla Firefox (Manifest V3), позволяющее управлять скоростью воспроизведения любых HTML5-видео на любой странице с помощью ползунка и готовых пресетов с полной синхронизацией между всеми вкладками.

---

## 🚀 Новые возможности (v1.1)

- **Диапазон до 5.0x**: максимальная скорость увеличена до `5.0x` (шаг `0.05x`).
- **Обновленные пресеты**: `1.0x`, `1.25x`, `1.5x`, `1.75x`, `2.0x`, `3.0x`, `4.0x`, `5.0x` (пресет `2.5x` убран).
- **Синхронизация между всеми вкладками**: изменение скорости в одном месте автоматически и мгновенно меняет скорость видео во всех открытых и новых вкладках.
- **Строка «Ускоряется: [Кнопка]»**: над ползунком отображается вкладка, где воспроизводится видео. Нажатие на кнопку мгновенно переключает браузер на эту вкладку.

---

## 🛠️ Как установить / обновить в Firefox

1. Откройте браузер **Firefox**.
2. В адресной строке введите:
   ```text
   about:debugging#/runtime/this-firefox
   ```
   и нажмите **Enter**.
3. В разделе **«Временные дополнения»** (Temporary Extensions):
   - Если расширение уже установлено: нажмите кнопку **«Перезагрузить»** (Reload).
   - Если устанавливаете впервые: нажмите **«Загрузить временное дополнение...»** (Load Temporary Add-on...) и выберите файл `manifest.json` в папке:
     `manifest.json` в папке репозитория.
4. Готово!

---

## 📁 Структура файлов

- `manifest.json` — конфигурация расширения (Manifest V3, права `storage`, `tabs`, `<all_urls>`).
- `content.js` — фоновый скрипт для страниц: применяет скорость ко всем `<video>`, слушает новые элементы и синхронизирует состояние.
- `popup.html` — разметка всплывающего окна (кнопка перехода к вкладке, ползунок до 5x, пресеты).
- `popup.css` — стили интерфейса в темной теме.
- `popup.js` — логика всплывающего окна, синхронизация через `storage.local` и переход по вкладкам.
- `icons/icon.svg` — иконка для панели инструментов.
